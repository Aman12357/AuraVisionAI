Meet AuraVision AI.

AuraVision is a creative workspace focused on text-to-image generation. The tools currently available depend on the deployed backend, configured image provider, and account limits. Video generation, music creation, live voice, and automated deep research are not enabled in this build. Visit the capabilities page for a clear breakdown.

Frequently asked questions

What can AuraVision do today?

The current core workflow is text-to-image generation in Studio, using an image provider configured by the service. The available controls and successful output depend on backend setup, account permissions, provider quota, and service availability. See all capabilities and their status.

Can AuraVision generate video or music?

Not in the current build. Video generation, music generation, and native audio features are not connected to this deployment. These links stay on AuraVision pages rather than sending you to another product.

Video generation status · Music generation status

Can I upload a photo as a reference image?

Photo-reference upload is not yet connected to Studio's generation request. You can use the gallery examples for inspiration and open Studio with a matching starting prompt, but the selected example itself is not sent as an image input.

Learn how image generation works.

How should I use generated content?

Review outputs before using them, only submit prompts or materials you have permission to use, and don't treat generated images as verified factual evidence. Read the AuraVision content guidelines.
